# Technology Stack: Parley

## 1. Core Technologies
*   **Language:** [TypeScript](https://www.typescriptlang.org/) - For type-safe application logic.
*   **Frontend Framework:** [Next.js (App Router)](https://nextjs.org/) - React framework for the application structure and routing.
*   **Backend:** Next.js API Routes and [Express](https://expressjs.com/) for specialized server-side logic.

## 2. AI & Narrative Engine
*   **Orchestration:** [LangChain](https://www.langchain.com/) & [LangGraph](https://langchain-ai.github.io/langgraph/) - For complex, stateful AI workflows.
*   **SDK:** [Vercel AI SDK](https://sdk.vercel.ai/) - For interacting with LLM providers.

## 3. State & Storage
*   **Global State:** [Zustand](https://zustand-demo.pmnd.rs/) - Lightweight state management for React.
*   **Local Persistence:** [Dexie.js](https://dexie.org/) - Wrapper for IndexedDB for robust client-side storage of game states.

## 4. UI & Styling
*   **CSS Framework:** [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS for rapid UI development.
*   **UI Primitives:** [Radix UI](https://www.radix-ui.com/) - Unstyled, accessible React components.
*   **Icons:** [Lucide React](https://lucide.dev/) - For consistent and modern iconography.

## 5. Development & Quality Assurance
*   **Component Documentation:** [Storybook](https://storybook.js.org/) - For isolated component development and testing.
*   **Testing:** [Jest](https://jestjs.io/) and [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/) - For unit and component testing.
